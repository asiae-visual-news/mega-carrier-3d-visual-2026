# 하늘이 두 번 합쳐집니다 | 아시아경제 비주얼뉴스

아시아경제 비주얼뉴스. 기사입력기 삽입 코드:

```html
<div id="vn1126air3d" data-top="0"></div><script src="https://asiae-visual-news.github.io/mega-carrier-3d-visual-2026/embed.js?v=1" charset="utf-8"></script>
```

- `embed.js` : 본문 삽입 스크립트 (화면·스타일·인터랙션 전부)
- `three-air.js` : three.js r160 + GLTFLoader + RoomEnvironment 묶음
- `models/` : 3D 비행기 모델 / `img/` : 이미지
- 고칠 때는 embed.js 수정 후 삽입 코드의 `?v=` 숫자를 올리면 캐시가 갱신됨
